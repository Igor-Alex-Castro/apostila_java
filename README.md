# Meu Guia de Estudos em Java

Este repositório foi organizado em duas grandes áreas para facilitar a aprendizagem:

- [Linguagem procedural/estrutural](./Linguagem%20proceduralestrutural/README.md): estudo da lógica de programação, estruturas de controle, operadores, arrays e fundamentos do Java em uma abordagem procedural.
- [POO (Programação Orientada a Objetos)](./POO/README.md): estudo de classes, objetos, encapsulamento, herança, polimorfismo e outros conceitos fundamentais da orientação a objetos.

### 2) POO (Programação Orientada a Objetos)

A partir daqui, o estudo passa a focar em modelagem de sistemas por meio de classes e objetos.

32. [Orientação a Objetos - Classes e Objetos](./POO/031-Orientacao-a-Objetos-Classes-e-Objetos/31-Orientacao-a-Objetos-Classes-e-Objetos.md)

## Sequência recomendada

1. Comece pela lógica procedural/estruturada para entender variáveis, estruturas e algoritmos.
2. Depois avance para POO para aprender a modelar problemas reais com classes e objetos.
3. Revise os conceitos com exercícios e pratique a escrita de código em Java.

## Observação

A organização em duas áreas deixa o estudo mais claro: primeiro você constrói a base da lógica e depois aplica esse conhecimento em modelagem orientada a objetos.
