# Exercícios de Java Procedural / Estrutural

Esta pasta reúne exercícios para reforçar todos os conceitos estudados na base da programação em Java.

## Objetivo

Treinar:

- lógica de programação
- entendimento de sintaxe e estruturas
- resolução de problemas cotidianos
- interpretação de problemas para entrevistas técnicas
- escrita de código limpa e legível

## Como estudar

1. Comece pelas perguntas teóricas para reforçar conceitos.
2. Depois resolva os exercícios práticos em Java.
3. Tente explicar seu raciocínio em voz alta, como em uma entrevista.
4. Revise o código após resolver e busque melhorar clareza e eficiência.

## Tópicos cobridos

- fundamentos da linguagem Java
- tipos primitivos e variáveis
- operadores aritméticos, relacionais e lógicos
- condicionais (`if`, `else`, `switch`)
- laços de repetição (`for`, `while`, `do-while`)
- arrays e matrizes
- lógica de decisão e de fluxo
- resolução de problemas de forma procedural

## Dica de estudo

Em entrevistas, o que mais importa não é memorizar sintaxe, e sim mostrar que você consegue:

- identificar o problema
- pensar em casos de teste
- estruturar a solução
- escrever código simples e funcional

Boa prática!
